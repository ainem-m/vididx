# T-10: vididx-vision — dHash + tesseract OCR

## 概要

dHash (差分ハッシュ)によるフレーム類似度計算と、tesseract OCR ラッパ。

## 実装ファイル

```
crates/vididx-vision/
└── src/
    ├── dhash.rs
    └── ocr.rs
```

## TDD手順

### dHash

- 2つのフレームのdHash値を計算
- ハミング距離を計算
- 同じ画像は距離0、異なる画像は距離>0

### OCR

- `TesseractAdapter` が trait を実装
- PNG/JPG → OCR テキスト抽出

## 依存

```toml
image = "0.25"
```
