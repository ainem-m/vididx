## TDD手順

### Red フェーズ: まずテストを書く

以下のテストが **失敗する** ことを確認してから実装に入ること。

**manifest のテスト**
- 空の `Manifest` を作って JSON ファイルに保存し、読み直すと同じ内容になる
- Stage を `done` で記録したあと `is_cached(stage_name, input_hash)` が `true` を返す
- `input_hash` が異なれば `is_cached` が `false` を返す
- `status` が `running` のままのStageは `is_cached` が `false` を返す

**Stage trait のテスト(ダミー実装)**
- `DummyStage` を実装し、`run()` が正しい Output を返す
- `cache_key()` が同じ Input に対して毎回同じ文字列を返す
- `cache_key()` が異なる Input に対して異なる文字列を返す

**runner統合テスト(ダミーStageで)**
- `JobContext` に `Manifest` を渡してダミーStageを実行すると、manifest にキャッシュが記録される
- 2回目の実行でキャッシュヒットし、`run()` が呼ばれない(モックで呼び出し回数を検証)

### Green フェーズ: 実装

#### `stage.rs`

```rust
use async_trait::async_trait;

/// パイプライン全体で共有されるジョブコンテキスト。
pub struct JobContext {
    pub video_id:   String,
    pub out_dir:    std::path::PathBuf,
    pub config:     vididx_core::config::Config,
    pub manifest:   std::sync::Arc<tokio::sync::Mutex<Manifest>>,
}

#[derive(Debug, thiserror::Error)]
pub enum StageError {
    #[error("stage {stage}: {source}")]
    Run { stage: &'static str, #[source] source: anyhow::Error },
    #[error("cache io: {0}")]
    CacheIo(#[from] std::io::Error),
    #[error("serde: {0}")]
    Serde(#[from] serde_json::Error),
}

#[async_trait]
pub trait Stage: Send + Sync {
    type Input:  serde::Serialize + Send + Sync;
    type Output: serde::de::DeserializeOwned + serde::Serialize + Send;
    const NAME: &'static str;

    async fn run(&self, ctx: &JobContext, input: Self::Input) -> Result<Self::Output, StageError>;

    /// 入力のSHA-256ハッシュ。キャッシュキーの一部として使う。
    fn cache_key(&self, input: &Self::Input) -> String {
        vididx_core::hash::sha256_str(&serde_json::to_string(input).unwrap_or_default())
    }
}
```

#### `manifest.rs`

SPEC.md §6.3 の Manifest 構造を実装する。

```rust
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct StageRecord {
    pub status:       StageStatus,   // "pending" | "running" | "done" | "failed"
    pub input_hash:   String,
    pub output_path:  String,
    pub completed_at: Option<chrono::DateTime<chrono::Utc>>,
}

#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
#[serde(rename_all = "snake_case")]
pub enum StageStatus { Pending, Running, Done, Failed }

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Manifest {
    pub manifest_version: String,   // "1.0"
    pub video_id:         String,
    pub source_path:      String,
    pub source_hash:      String,
    pub config_hash:      String,
    pub stages:           std::collections::BTreeMap<String, StageRecord>,
}

impl Manifest {
    pub fn new(video_id: &str, source_path: &str, source_hash: &str, config_hash: &str) -> Self
    pub fn load(path: &Path) -> Result<Self, StageError>
    pub fn save(&self, path: &Path) -> Result<(), StageError>

    /// stage_name の input_hash が一致し、status == Done ならキャッシュヒット。
    pub fn is_cached(&self, stage_name: &str, input_hash: &str) -> bool

    pub fn mark_running(&mut self, stage_name: &str, input_hash: &str)
    pub fn mark_done(&mut self, stage_name: &str, output_path: &str)
    pub fn mark_failed(&mut self, stage_name: &str)
}
```

**キャッシュキー算出**(SPEC.md §6.3):
```
input_hash = sha256(canonicalize_json(stage_input) ‖ config_hash ‖ source_hash ‖ stage_name)
```

`canonicalize_json` はキーをソートした決定論的なJSON文字列。`serde_json::to_string` は保証されないためキーソートが必要。
