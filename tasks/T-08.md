# T-08: vidx-media — フレーム抽出

## 概要

指定秒数のフレームを JPEG で抽出。バッチ実行で複数秒数に対応。

## 実装

```rust
pub async fn extract_frames(
    ffmpeg_path: &str,
    mp4_path: &Path,
    seconds: &[f64],
    out_dir: &Path,
    quality: u8,  // 85
) -> Result<Vec<PathBuf>, VidxError>
```

実装:
- 秒数ごとに `ffmpeg -ss {t} -i {mp4} -frames:v 1 -q:v 3 {out}.jpg`
- 並列実行で効率化 (tokio::join_all)
