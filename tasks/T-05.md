# T-05: vidx-media — 音声抽出

## 概要

mp4 から音声を16kHz mono WAV で抽出する。ASR入力の前処理。

## 依存タスク

- T-01, T-04 完了済み

## 対象クレート

`crates/vidx-media/src/audio.rs`

## 実装

```rust
pub async fn extract_audio(
    ffmpeg_path: &str,
    mp4_path: &Path,
    output_wav_path: &Path,
) -> Result<(), VidxError>
```

実装:
1. `ffmpeg -i {mp4} -ac 1 -ar 16000 {output_wav}` を実行
2. 存在確認、エラーハンドリング

## テスト

- ffmpeg が存在しない場合 `ToolNotFound`
- 出力ファイルが16kHz mono WAV で生成される
