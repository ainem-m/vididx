# T-02: vidx-core — config / config_hash

## 概要

`vidx.toml` を読み込む設定モジュールを実装する。
優先順位(環境変数 > CLI flag > toml > default)と `config_hash()` を実装する。

## 依存タスク

- T-01 完了済みであること(`vidx-core` の基盤が整っていること)

## 対象クレート

`crates/vidx-core/` に `config.rs` を追加する。

## 実装ファイル

```
crates/vidx-core/src/config.rs
```

## TDD手順

### Red フェーズ: まずテストを書く

以下のテストが **失敗する** ことを確認してから実装に入ること。

**デフォルト値のテスト**
- `Config::default()` で `segment.coarse.max_duration_sec == 300.0` になる
- `Config::default()` で `frames.periodic_interval_sec == 5.0` になる
- `Config::default()` で `llm.max_concurrency == 4` になる

**TOML読み込みのテスト**
- 部分的なTOMLを渡したとき、指定したフィールドだけ上書きされ残りはデフォルト値になる
- 不正なTOML文字列を渡したとき `VidxError::Config` が返る

**config_hash のテスト**
- 同じ `Config` から生成したハッシュは毎回一致する
- フィールドを1つ変えると異なるハッシュになる
- ハッシュは `"sha256:"` プレフィックスで始まる

**環境変数オーバーライドのテスト**
- `ANTHROPIC_API_KEY` 環境変数がセットされていれば `config.secrets.anthropic_api_key` に反映される
  (テスト内で `std::env::set_var` を使い、テスト後に戻す)

### Green フェーズ: 実装

#### 設定構造体

SPEC.md §8 の `vidx.toml` に対応した構造体を定義する。

```rust
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct Config {
    pub general:  GeneralConfig,
    pub media:    MediaConfig,
    pub segment:  SegmentConfig,
    pub frames:   FramesConfig,
    pub asr:      AsrConfig,
    pub vision:   VisionConfig,
    pub llm:      LlmConfig,
    pub output:   OutputConfig,
    pub secrets:  SecretsConfig,
}
```

各サブ構造体もSPEC.md §8に従い定義する。すべてのフィールドに `Default` を実装する。

#### ロード優先順位

```rust
pub fn load(toml_path: Option<&Path>) -> Result<Config, VidxError>
```

1. `Config::default()` で初期値を作る
2. `toml_path` が `Some` なら読み込んでフィールドを上書き
3. `toml_path` が `None` なら `./vidx.toml` → `~/.config/vidx/config.toml` の順に探す(見つからなければデフォルトのまま)
4. 環境変数で `secrets` フィールドを上書き(SPEC.md §8 `[secrets]` 参照)

CLI flagによる上書きは `vidx-cli` 側で行うため、このモジュールはファイル+環境変数までを担当する。

#### config_hash

```rust
impl Config {
    /// 設定内容のSHA-256ハッシュを返す。キャッシュキー計算に使う。
    pub fn config_hash(&self) -> String
}
```

`serde_json::to_string` でシリアライズしてから `hash::sha256_str` に渡す。
ただし `secrets` フィールドはハッシュ計算から除外する(APIキーが変わっても再実行しない)。
