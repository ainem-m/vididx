## TDD手順

### Red フェーズ

- `ffprobe` コマンド存在チェックがない場合 `VidxError::ToolNotFound` を返す
- 正常な mp4 を渡すと `MediaProbe { duration_sec, fps, resolution, has_video, has_audio }` が返る
- 存在しないファイルを渡すと error を返す
- ffprobe が JSON を返さない場合 (コマンド失敗) error を返す

### Green フェーズ

```rust
pub async fn probe(ffprobe_path: &str, mp4_path: &Path) -> Result<MediaProbe, VidxError>
```

実装:
1. `which ffprobe_path` で存在確認。なければ `VidxError::ToolNotFound`
2. `ffprobe -v error -show_entries format=duration -show_entries stream=...` を実行
3. JSON 出力をパースして MediaProbe を構築
4. duration, fps, resolution, has_video, has_audio を抽出
