# T-13: vididx-llm — LLM クライアント

Anthropic Messages API クライアント。JSON mode + リトライ + 同時実行制限。

## 実装

```rust
pub struct AnthropicClient {
    api_key: String,
    model: String,
    max_concurrency: usize,
}

pub async fn call_with_json_mode(
    &self,
    system_prompt: &str,
    user_message: &str,
) -> Result<serde_json::Value, VididxError>
```

## 機能

- API キー管理
- リトライ (指数バックオフ, max 3回)
- 同時実行制限 (Semaphore)
- タイムアウト (30秒)
