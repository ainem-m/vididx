# T-12: vididx-segment — 粗分割(coarse)

ハイブリッド粗分割: 300秒フレーム + 補助信号(無音/画面変化)へのスナップ。

## 実装

```rust
pub fn coarse_segment(
    duration_sec: f64,
    transcript: &TranscriptTimeline,
    silence_intervals: &[SilenceInterval],
    scene_changes: &[SceneChange],
    max_duration: f64,
    snap_window: f64,
) -> Result<Vec<CoarseSegment>, VididxError>
```

## アルゴリズム

1. 動画を`max_duration`フレーム(300s)で仮想分割
2. 各フレーム境界の±`snap_window`(30s)に補助信号あれば、そこへスナップ
3. なければそのまま`max_duration`で切る
4. 各セグメントに対応する transcript を連結
