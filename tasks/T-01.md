# T-01: vididx-core — model / error / hash

## 概要

`vididx-core` クレートの基盤となる3モジュールを実装する。
他のすべてのクレートがこのクレートに依存するため、最初に完成させる。

## 対象クレート

`crates/vididx-core/`

## 実装ファイル

```
crates/vididx-core/
├── Cargo.toml
└── src/
    ├── lib.rs
    ├── model.rs   # ドメイン型定義
    ├── error.rs   # VididxError
    └── hash.rs    # sha256 ヘルパ
```

## TDD手順

### Red フェーズ: まずテストを書く

以下のテストが **失敗する** ことを確認してから実装に入ること。

**model.rs のテスト**
- `Chunk` を serialize → deserialize してフィールドが一致する
- `ContentType` の各バリアントが snake_case でシリアライズされる(例: `"screen_recording"`)
- `FrameKind` の各バリアントが snake_case でシリアライズされる

**error.rs のテスト**
- `VididxError::Io` が `std::io::Error` から `From` で変換できる
- `VididxError::Serde` が `serde_json::Error` から `From` で変換できる
- `Display` トレイトで意味のあるメッセージが出る

**hash.rs のテスト**
- 同じバイト列を渡すと毎回同じハッシュ文字列が返る
- 異なるバイト列は異なるハッシュになる
- 出力形式が `"sha256:<hex64文字>"` になっている

### Green フェーズ: 実装

#### `error.rs`

SPEC.md §13 の `VididxError` をそのまま実装する。

```rust
#[derive(Debug, thiserror::Error)]
pub enum VididxError {
    #[error("media error: {0}")]            Media(String),
    #[error("asr error: {0}")]              Asr(String),
    #[error("llm error: {0}")]              Llm(String),
    #[error("vision error: {0}")]           Vision(String),
    #[error("segment error: {0}")]          Segment(String),
    #[error("config error: {0}")]           Config(String),
    #[error("io error: {0}")]               Io(#[from] std::io::Error),
    #[error("serde error: {0}")]            Serde(#[from] serde_json::Error),
    #[error("external tool not found: {0}")] ToolNotFound(String),
}
```

#### `hash.rs`

- `pub fn sha256_bytes(data: &[u8]) -> String` — `"sha256:<hex>"` 形式で返す
- `pub fn sha256_str(s: &str) -> String` — 文字列版ショートハンド
- `pub fn sha256_file(path: &Path) -> Result<String, VididxError>` — ファイルを読んでハッシュ

#### `model.rs`

SPEC.md §6.2 の Rust 型定義を完全に実装する。省略されている型も含めてすべて定義する。

実装すべき型:
- `ContentType` (enum)
- `FrameKind` (enum)
- `ModalityFlags`
- `ImageRef`
- `SourceJumpRef` — `{ type: String, start_sec: f64 }`
- `ProcessingMeta` — `{ segmentation_rationale: Option<String>, asr_adapter: String, vlm_adapter: String, generated_at: DateTime<Utc> }`
- `Chunk` (メインの出力型)
- `MediaProbe` — `{ duration_sec: f64, fps: f64, resolution: (u32,u32), has_video: bool, has_audio: bool }`
- `TranscriptSegment` — `{ start_sec: f64, end_sec: f64, text: String, speaker: Option<String>, confidence: Option<f32> }`
- `TranscriptTimeline` — `{ segments: Vec<TranscriptSegment> }`
- `SilenceInterval` — `{ start_sec: f64, end_sec: f64 }`
- `SceneChange` — `{ at_sec: f64, score: f64 }`
- `CoarseSegment` — `{ index: usize, start_sec: f64, end_sec: f64, transcript_text: String }`
- `SemanticChunk` — `{ start_sec: f64, end_sec: f64, transcript_text: String, rationale: String }`
- `NormalizedChunk` — `{ chunk_id: String, parent_segment_id: String, start_sec: f64, end_sec: f64, transcript_text: String }`
- `ExtractedFrame` — `{ path: PathBuf, at_sec: f64, kind: FrameKind, chunk_id: String, analyze: bool }`
- `FrameAnalysis` — `{ frame_path: PathBuf, ocr_text: Option<String>, visual_caption: Option<String> }`
- `AnnotatedChunk` — `NormalizedChunk` に `title`, `summary`, `keywords: Vec<String>` を加えたもの
